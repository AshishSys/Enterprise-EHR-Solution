# Wisconsin Statewide EHR Platform

Cloud-native statewide Electronic Health Record platform for Wisconsin enabling care coordination, care gap closure, and improved outcomes.

## Stack

- **Google Cloud Platform** — application hosting, FHIR store, AI/ML
- **Microsoft Fabric** — ETL and data engineering
- **Snowflake** — reporting views and semantic layer
- **Power BI** — analytics and dashboards

## Documentation

See [docs/WISCONSIN_EHR_SOLUTION_BLUEPRINT.md](docs/WISCONSIN_EHR_SOLUTION_BLUEPRINT.md) for the full solution design covering pre-sales, architecture, data models, implementation, UAT, go-live, and Cerner migration.
